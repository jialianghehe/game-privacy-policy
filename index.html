一、我们如何收集和使用您的个人信息

我们遵循合法、正当、必要和诚信原则，按照游戏实际提供的功能处理所需信息。下列功能中的云服务、账号绑定和排行榜，以您所使用版本实际开放的功能为准。

1. 游客进入及本地游戏

您可以使用游客方式体验游戏。游戏可能在设备本地保存游戏进度、角色属性、背包、设置及相关操作记录，以支持继续游戏和读取本地存档。这些本地数据通常保存在应用的本地存储空间；仅保存于本地的数据不会因为本政策的描述而自动上传到服务器。

2. 可选的账号绑定

如果您主动选择绑定账号，我们会处理实现身份识别和绑定所必需的账号标识、绑定凭据及对应的游戏记录。具体绑定方式与是否涉及手机号、邮箱或第三方登录，请以游戏实际界面为准；【待核实：明确绑定方式与字段】。不选择绑定可能无法使用依赖身份识别的找回功能。

3. 手动上传或恢复云存档

在您主动点击“上传存档”或“从云端恢复”等操作时，我们需要处理关联账号标识、存档内容、上传或恢复时间及必要的服务请求信息，以实现存档上传、下载和管理。游戏不因您进入游戏就默认自动上传完整游戏存档；【待核实：核对实际版本是否确实关闭自动云存档】。

4. 战力排行榜

在您主动使用战力排行榜上传功能时，我们可能处理您在榜单使用的展示名称、与排行榜关联的用户标识、战力数值、上传时间和必要的防滥用记录，用于展示和管理排行榜。排行榜展示信息可能被其他玩家看到，请避免在公开昵称中使用手机号、身份证号等敏感信息。

5. 网络连接、服务安全与故障处理

使用云服务、账号功能或排行榜时，服务器或所接入的服务提供商可能处理 IP 地址、网络请求时间、接口访问日志、错误信息及必要的设备／应用版本信息，用于实现网络通信、保障安全、排查故障和防止服务被滥用。实际采集字段应根据服务端日志和已接入 SDK 核实；【待核实：网络日志与设备信息字段】。

6. 充值、实名认证、广告及其他功能

本草案未将充值、第三方广告、实名认证或防沉迷 SDK 认定为当前已经接入的功能。如当前发布版本实际提供这些功能，应在发布前补充其必要的数据类型、处理目的、第三方服务商与法律依据，并根据法律要求履行相应告知及授权程序。

7. 设备权限

为完成联网操作，应用需要使用网络通信能力。对于读取或写入由您选择的存档文件等操作，应用可能通过系统提供的文件选择界面访问您主动选择的文件。对于需由系统弹窗授权的权限，我们将在实际调用前告知用途，并尊重您的选择。【待核实：以最终 APK 的 AndroidManifest、运行时权限及 SDK 权限清单为准；不得声称未使用的权限已申请。】

二、我们如何保存您的个人信息

本地游戏数据保存在您使用的设备中，通常可以通过游戏功能或系统应用管理操作删除。请注意，卸载游戏或清除应用数据可能导致尚未备份的本地进度无法恢复。

对于您主动上传的云存档、排行榜及账号数据，我们原则上仅在实现功能所必要的最短期限或法律规定的期限内保存；到期后依照法律规定删除或匿名化处理。若您请求注销或删除，我们将依据合法要求核验并处理；法定保存期限未届满的除外。

【待核实：列明实际云服务提供商、服务器／存储地域、具体保存期限或确定规则，以及备份删除周期。】未经核实，不应声称所有信息都必然存储于某一地区。

本游戏可能通过 Android WebView 的本地存储功能（例如 localStorage 或 IndexedDB）保存必要的游戏状态、设置或会话标识。若实际网页内容或第三方 SDK 使用 Cookie 或类似技术，也应仅为实现相应功能而使用，并按照实际情况提供说明。

【待核实：检查游戏 WebView、网页内容及 SDK 是否使用 Cookie、广告标识符、分析工具或跨站跟踪；若没有实际使用，不应添加推荐广告等不相关描述。】

四、我们如何共享、转让及公开披露个人信息

我们不会为无关目的出售您的个人信息。为实现已启用的云服务、账号、排行榜等功能，我们可能需要向为我们提供基础设施及技术服务的合作方提供实现服务所必需的信息，并依法明确处理目的、数据种类和安全要求。具体合作方请参见第五部分。

如涉及合并、分立、解散、破产或其他依法需要转移个人信息的情形，我们将按照法律规定告知您相关情况，并要求接收方继续依法保护个人信息。

除您主动上传排行榜展示数据、依法取得授权或法律法规另有规定等情况外，我们不会随意公开披露您的个人信息。

六、我们如何保护您的个人信息

我们采取与数据类型、处理规模和风险相适应的访问控制、身份鉴别、传输保护、权限管理、日志审计与数据备份等合理措施，降低未经授权访问、泄露、篡改和丢失的风险。具体措施以实际部署情况为准。

互联网环境无法保证绝对安全。如发生或可能发生个人信息泄露、篡改、丢失，我们将依法采取补救措施，并在依法需要时告知受影响用户及有关主管部门。

七、您如何管理您的个人信息

1. 查询、更正与复制

您可以在游戏提供的相应页面查看可展示的账号、角色和存档信息。如需查询、复制或更正其他个人信息，可以通过本政策第十部分的联系方式提出请求。

2. 删除存档和个人信息

您可以通过游戏提供的相应功能管理本地存档；如需删除云存档、排行榜关联数据或其他个人信息，请通过本政策第十部分的联系方式提出申请。我们会在核验必要信息后依法处理。删除云端数据不会自动清除您设备中单独保存的本地备份。

3. 撤回授权与注销账号

您可以在系统设置中管理可撤回的设备权限，或通过本政策第十部分联系运营者申请撤回非必要的授权、解除账号绑定或注销账号（如对应功能已经开放）。撤回某项必要授权可能导致相应功能不能继续使用，但不影响此前合法处理活动的效力。

4. 响应期限及申诉

收到您的请求后，我们将核验请求人的身份并在法律规定的期限内处理。对于可能涉及他人权益、法律规定需保存或依法不宜披露的信息，我们将依法说明处理结果。您也可以向有权监管机关投诉。

八、我们如何处理未成年人的个人信息

我们重视未成年人个人信息保护。未成年人应当在监护人指导下阅读本政策，并按照适用法律及游戏实际要求使用相关服务。处理不满十四周岁未成年人的个人信息时，我们将依法取得其父母或者其他监护人的同意，并遵守适用的特别保护要求。

如游戏接入实名认证、防沉迷或未成年人保护功能，我们将根据实际接入方式、适用法律和相关服务商规则单独说明信息处理情况。【待核实：发布渠道要求、实名认证及防沉迷的实际实现情况。】

九、本隐私政策如何更新

我们可能因游戏功能、个人信息处理方式或适用法律变化而更新本政策。更新后的政策将通过游戏内入口或本网页发布；涉及处理目的、方式、信息种类等重大变化的，我们会依法以适当方式显著告知，并在必要时重新取得同意。
